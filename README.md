# Food Freshness Classifier

AI-based system that classifies food freshness using image analysis.

- AI predicts freshness level
- Web interface for easy testing

## Tech Stack
- Python
- Machine Learning
- Flask / FastAPI
- HTML / CSS / JavaScript

pip install -r requirements.txt
